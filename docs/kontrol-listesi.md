# Göndermeden Önce Kontrol Listesi

## Biçim
- [ ] Tek sütun, tablo/metin kutusu yok
- [ ] Fotoğraf, ikon, grafik yok
- [ ] Sade yazı tipi, 10–12 pt
- [ ] Maksimum 2 sayfa
- [ ] Metin tabanlı PDF veya DOCX (metni fareyle seçebiliyorum)
- [ ] Dosya adı: `Ad_Soyad_CV.pdf`

## İçerik
- [ ] Ad soyad, e-posta, telefon, şehir, LinkedIn sayfa gövdesinde
- [ ] Standart başlıklar kullanıldı
- [ ] Tarihler tutarlı ve ters kronolojik sırada
- [ ] Her deneyimde pozisyon, şirket, tarih var
- [ ] Maddeler eylemle başlıyor ve ölçülebilir sonuç içeriyor
- [ ] Yazım ve dil hatası yok

## Anahtar kelime
- [ ] İlanın zorunlu gereksinimlerini inceledim
- [ ] Sahip olduğum terimleri ilandaki yazımıyla kullandım
- [ ] `python tools/ats_check.py cv.md ilan.txt` eşleşme oranı kabul edilebilir
- [ ] Sahip olmadığım hiçbir beceriyi yazmadım
